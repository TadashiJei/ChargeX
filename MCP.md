# ChargeX - Minimum Callable Product (MCP)

## Project Overview
ChargeX is a comprehensive EV charging management system that consists of multiple components:
- Web Application Dashboard
- API Backend
- IoT Device Integration
- Smart Contract Integration (Hardhat)
- Raspberry Pi GUI Interface

## Core Features for MCP

### 1. Web Dashboard (Priority: High)
- User authentication and authorization
- Basic charging station management
  - View station status
  - Start/stop charging sessions
  - View charging history
- Simple payment integration
- Basic analytics dashboard

### 2. API Backend (Priority: High)
- RESTful API endpoints for:
  - User management
  - Station management
  - Session management
  - Payment processing
- Database integration
- Authentication middleware
- Basic error handling

### 3. IoT Integration (Priority: Medium)
- Basic device communication protocol
- Real-time status updates
- Simple command interface
- Basic error reporting

### 4. Smart Contract Features (Priority: Medium)
- Basic payment smart contract
- Simple token management
- Transaction history

### 5. Raspberry Pi Interface (Priority: Low)
- Basic GUI for station control
- Status display
- Simple user interface for charging

## Technical Requirements

### Frontend
- Next.js/React
- Web3 integration
- Real-time updates
- Responsive design

### Backend
- Java Spring Boot
- PostgreSQL/MySQL
- Redis for caching
- JWT authentication

### IoT
- MQTT protocol
- Basic security implementation
- Status monitoring

### Blockchain
- Ethereum compatibility
- Basic smart contract deployment
- Web3 integration

## Success Criteria
1. Successfully complete a charging session end-to-end
2. Process a payment transaction
3. Real-time status updates working
4. Basic user management functional
5. Simple analytics dashboard operational
